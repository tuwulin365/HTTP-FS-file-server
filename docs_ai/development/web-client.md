# Web client development

## Setup

```bash
cd client
npm install
```

## Develop

1. Edit files under `client/src/` (JS, CSS, HTML, lang JSON).
2. `npm run build` — inspect `client/dist/`.
3. `npm run deploy` — replaces `app/src/main/assets/web/template/`.
4. Rebuild/install the Android app.
5. Start the server and hard-refresh the browser (cache).

## Runtime `config.js`

Generated by `HtmlBuilder` when serving pages. Do not expect a hand-edited `config.js` in assets to be the live source of feature flags.

## i18n

Language packs live under `client/src/assets/lang/`. Server/app language settings influence which UI language is injected.

## Do not break URLs

Public paths such as `/web/template/...` and `/files/...` are coupled to Android route constants. Coordinate server + client changes.

See [../modules/client.md](../modules/client.md).
