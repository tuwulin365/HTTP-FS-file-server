# Free vs Pro (users)

Same product, two apps:

| | Free | Pro |
|---|------|-----|
| Default port | 8080 | 8081 |
| Ads | Yes (privacy options + optional rewarded “disable ads”) | No |
| Multiple users | Limited | Yes |
| Redirects | No | Yes (experimental) |
| Hidden files list | Limited / Pro‑gated persistence | Yes |
| Welcome message text | Limited | Full |
| Home screen widgets / start shortcut | No | Yes |
| Blocked IP count | Capped | Unlimited |
| HTTP / WebDAV / API / RSS / SSL library | Yes | Yes |

Upgrade prompts appear when you hit a Free limit. Technical flavor notes: [../overview/free-vs-pro.md](../overview/free-vs-pro.md).
