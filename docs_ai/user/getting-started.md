# Getting started

## Install

- **Free** or **Pro** from the store (or a build you installed yourself).
- Both can be installed together (different apps). Defaults: Free port **8080**, Pro **8081**.

## First run

1. Allow **notifications** (Android 13+) so the ongoing server notification can stay visible.
2. Allow **storage / files** access as prompted. For SD cards use **Settings → App → Storage permissions** (or folder permission) when asked.
3. Open **Home** and tap **Start**.
4. Read the URL from the home screen or the notification, for example `http://192.168.1.20:8080`.
5. On another device on the **same Wi‑Fi**, open that URL in a browser.

Stop the server from the app or the notification **Stop** action.

## Keep it running with the screen off

1. Leave the server started (notification must remain).
2. In **Settings → App**, enable **Battery permissions** / ignore battery optimizations when offered.
3. On aggressive OEM skins, also allow auto‑start if you use **Start server with device**.

## Optional next steps

- Pick a narrower **Path to folder** instead of sharing everything — [settings guide](settings-guide.md).
- Turn on **Use password** for guests on the LAN.
- Enable **SSL** and pick a certificate — [HTTPS & certificates](https-certificates.md).
- Mount **WebDAV** — [Connect clients](connect-clients.md).

## Android TV

Install, start the server the same way. Settings use D‑pad focus; on certificate lists, **long‑press** opens Edit where phone UI uses an icon.
