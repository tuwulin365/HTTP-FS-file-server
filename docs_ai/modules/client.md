# Web client (`client/`)

Not a Gradle module. Source for the browser file manager served by HttpFS.

## Pipeline

```text
client/src/  --npm run deploy-->  app/src/main/assets/web/template/
                                      │
                                      ▼
                              Browser: /web/template/...
                              HtmlBuilder injects config.js at runtime
```

## Commands

```bash
cd client
npm install
npm run build     # → client/dist/
npm run deploy    # build + replace assets/web/template/
```

After deploy, rebuild the Android APK.

## Stack

- Vanilla JS + jQuery
- esbuild bundle (`build.mjs`) → `app.js` / `app.css`
- i18n JSON under `client/src/assets/lang/`

## Runtime config

`config.js` is **generated by the server** (`HtmlBuilder`), not shipped as a static source of truth. It carries rights, feature flags, branding, language, etc.

## Editing tips

- Edit only under `client/src/`.
- `client/dist/` is build output (gitignored).
- Keep public URL paths stable (`/web/template/...`) unless you update server routes too.
